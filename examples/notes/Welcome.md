# Welcome to margin

margin is a **terminal markdown notes editor**. Every note is a plain `.md` file in a folder, so your notes work with git, grep, Obsidian, or any other editor.

## Getting around

- `j` / `k` move through the tree, `l` / `h` open and close folders
- `e` edits the note, `esc` saves and shows the rendered view again
- `ctrl+p` finds a note by name, `ctrl+f` searches inside every note
- `?` lists every key

> Notes save automatically while you type.
